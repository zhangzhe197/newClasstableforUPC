由于学校再次更新教务系统，原有的模拟登录方法已失效，因此本程序不再采用模拟登录的方式获取课表数据。新的解决方案是利用教务系统提供的课表导出功能，将课表导出为XLS文件，然后使用本程序将XLS文件转换为ICS文件。

具体使用方法如下：

1. **导出课表XLS文件：**  登录新的教务系统，找到课表所在页面，使用系统提供的导出功能，将你的课表导出为XLS文件。请确保导出的XLS文件包含完整的课表信息，例如课程名称、上课时间、地点、教师等。

2. **修改程序中的文件路径：**  在代码中找到 `classdf = readXls('/home/zhangzhe/Downloads/tar.xls')`  这一行，将 `/home/zhangzhe/Downloads/tar.xls`  替换为你导出的XLS文件的完整路径。

3. **设置学期起始日期：**  找到代码中 `termStartDate = datetime.datetime(2025,2,24)`  这一行，将 `2025,2,24`  替换为你所在学期第一周的**星期一**的日期。请务必确保日期准确，否则会导致生成的ICS文件中课程时间错误。日期格式为 `年,月,日`。

4. **运行程序：**  保存修改后的代码，然后运行程序。程序会读取XLS文件中的课表信息，并将其转换为ICS格式的日历文件，保存为 `classtable.ics` 文件。

5. **导入日历：**  将生成的 `classtable.ics` 文件导入到你的日历应用程序中，例如Google Calendar、Outlook等。


**注意事项：**

* 请确保你的Python环境已安装必要的库，例如 `pandas`、`xlrd` 等。可以使用 `pip install pandas xlrd` 命令安装。
*  本程序依赖于教务系统导出的XLS文件的格式。
*  请仔细检查生成的ICS文件，确保其中的课程信息准确无误。
